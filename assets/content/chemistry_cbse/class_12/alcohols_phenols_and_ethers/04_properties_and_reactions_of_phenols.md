# 1. Pedagogical Theory, Structure, and Acidity of Phenols

***

### 1.1 Structural Features & Resonance Hybrid of Phenol
**Priority:** ⭐⭐⭐⭐⭐

* **Molecular Formula:** $\mathrm{C_6H_5OH}$ (Benzenol / Hydroxybenzene)
* **Hybridization:** The oxygen atom of the hydroxyl group ($-\mathrm{OH}$) is bonded to an $sp^2$-hybridized carbon atom of the aromatic ring.
* **Bond Characteristics:**
  * The $\mathrm{C-O}$ bond length in phenol is **$136\text{ pm}$**, which is significantly shorter than the $\mathrm{C-O}$ bond length in methanol (**$142\text{ pm}$**).
  * **Two Underlying Physical Causes:**
    1. **Partial Double Bond Character:** Conjugation of the unshared electron pairs of oxygen with the $\pi$-electron system of the aromatic ring.
    2. **Electronegativity Difference of Carbon:** The oxygen is attached to an $sp^2$-hybridized carbon (higher $s$-character, $33.3\%$, more electronegative) compared to an $sp^3$-hybridized carbon in aliphatic alcohols ($25\%$, less electronegative).

```
Resonance Structures of Phenol:
  :O-H            +O-H            +O-H            +O-H            :O-H
   ..              ..              ..              ..              ..
 /    \         /    \(-)       /    \           /(-) \         /    \
|      |  <->  |      |   <->  |      |   <->   |      |  <->  |      |
 \    /         \    /          \(-) /           \    /         \    /
   (I)            (II)            (III)            (IV)            (V)
```

$$
\text{Dipole moment of phenol } (\mu = 1.54\text{ D}) < \text{Dipole moment of methanol } (\mu = 1.71\text{ D})
$$

*Reason:* The aromatic ring exerts a strong electron-withdrawing inductive/resonance effect ($-I$ and $+R$), pulling electron density away from oxygen toward the ring, opposing the $\mathrm{C}^{\delta+}-\mathrm{O}^{\delta-}$ bond dipole.

***

### 1.2 Nature of Acidity: Comparative Analysis
**Priority:** ⭐⭐⭐⭐⭐

#### Phenol vs. Aliphatic Alcohols
Phenols react with electropositive metals ($\mathrm{Na}$, $\mathrm{K}$) as well as aqueous alkali ($\mathrm{NaOH}$), whereas aliphatic alcohols react only with reactive metals ($\mathrm{Na}$, $\mathrm{K}$) and do **not** react with aqueous $\mathrm{NaOH}$.

$$
\mathrm{C_6H_5OH + NaOH(aq) \rightleftharpoons C_6H_5O^-Na^+ + H_2O}
$$

$$
\mathrm{R-OH + NaOH(aq) \rightarrow \text{No Reaction (alcohols are weaker acids than water)}}
$$

```
Resonance Structures of Phenoxide Ion:
  :O:(-)          :O:             :O:             :O:             :O:(-)
   ..              ..              ..              ..              ..
 /    \         /    \(-)       /    \           /(-) \         /    \
|      |  <->  |      |   <->  |      |   <->   |      |  <->  |      |
 \    /         \    /          \(-) /           \    /         \    /
   (I)            (II)            (III)            (IV)            (V)
```

**Rigorous Resonance Interpretation (NCERT Criterion):**
1. In un-ionized phenol, structures II, III, and IV involve **charge separation** (positive charge on the highly electronegative oxygen atom and negative charge dispersed on ring carbons). Charge separation destabilizes the canonical forms.
2. In the phenoxide ion ($\mathrm{C_6H_5O^-}$), there is **no charge separation**. The negative charge is delocalized over the ortho and para positions of the benzene ring.
3. Therefore, the phenoxide ion is **more resonance-stabilized** than neutral phenol. The equilibrium shifts toward ionization:
   

$$
\mathrm{C_6H_5OH + H_2O \rightleftharpoons C_6H_5O^- + H_3O^+} \quad (pK_a \approx 10.0)
$$

#### Quantitative Acidity Comparison ($pK_a$ Values at $298\text{ K}$)

$$
\text{Picric acid } (0.78) < 2,4\text{-Dinitrophenol } (4.0) < 4\text{-Nitrophenol } (7.15) < 2\text{-Nitrophenol } (7.23) < \text{Phenol } (9.98) < m\text{-Cresol } (10.08) < p\text{-Cresol } (10.26) < \text{Ethanol } (15.9)
$$

$$
\boxed{\text{Acid Strength} \propto K_a \propto \frac{1}{pK_a}}
$$

### 1.3 Substituent Effects on Acidity
**Priority:** ⭐⭐⭐⭐⭐

1. **Electron-Withdrawing Groups (EWGs) ($-I, -M/-R$):**
   * Groups like $-\mathrm{NO_2}, -\mathrm{CN}, -\mathrm{X}, -\mathrm{CHO}, -\mathrm{COOH}$.
   * **Mechanism:** Disperse the negative charge of the phenoxide ion by drawing electron density through resonance and inductive pathways.
   * **Position Dependency:** The $-R$ effect operates exclusively at **ortho** and **para** positions. At the **meta** position, $-\mathrm{NO_2}$ stabilizes the phenoxide ion solely via the weaker $-I$ effect.
   * *Order:* $4\text{-nitrophenol} > 2\text{-nitrophenol} > 3\text{-nitrophenol} > \text{phenol}$
   * *Anomaly (ortho vs. para):* 4-Nitrophenol ($pK_a = 7.15$) is slightly more acidic than 2-nitrophenol ($pK_a = 7.23$) due to **intramolecular hydrogen bonding** (chelation) in 2-nitrophenol, which stabilizes the undissociated molecule and hinders the release of the proton.

2. **Electron-Donating Groups (EDGs) ($+I, +H, +R$):**
   * Groups like $-\mathrm{CH_3}, -\mathrm{OCH_3}, -\mathrm{NH_2}$.
   * **Mechanism:** Intensify the negative charge on the phenoxide ion, destabilizing it and decreasing acid strength.
   * For cresols (methylphenols), hyperconjugation ($+H$) and $+I$ operate at ortho/para, while only $+I$ operates at meta:
     

$$
\text{Acidic Strength: } \text{Phenol} > m\text{-cresol} > p\text{-cresol} > o\text{-cresol}
$$

# 2. Complete Chemical Reactions, Mechanisms & Industrial Processes

### 2.1 Reactions Involving Cleavage of $\mathrm{O-H}$ Bond (Acylation & Esterification)
**Priority:** ⭐⭐⭐⭐

Phenols react with acid chlorides or acid anhydrides in the presence of a base (pyridine) to yield phenyl esters. Pyridine neutralizes the byproduct $\mathrm{HCl}$, shifting the equilibrium forward.

$$
\mathrm{C_6H_5OH + CH_3COCl \xrightarrow{\text{Pyridine}} C_6H_5OCOCH_3 + HCl}
$$

#### Synthesis of Aspirin (Acetylation of Salicylic Acid)
Salicylic acid (2-hydroxybenzoic acid) reacts with acetic anhydride in the presence of concentrated $\mathrm{H_2SO_4}$ acting as an acid catalyst:

$$
\mathrm{C_6H_4(OH)(COOH) + (CH_3CO)_2O \xrightarrow{\text{conc. } H_2SO_4} C_6H_4(OCOCH_3)(COOH) + CH_3COOH}
$$

$$
\boxed{\text{Salicylic Acid} + \text{Acetic Anhydride} \rightarrow \text{Acetylsalicylic Acid (Aspirin)} + \text{Ethanoic Acid}}
$$

* **Key Detail:** The phenolic $-\mathrm{OH}$ group is acetylated, **not** the carboxylic acid $-\mathrm{COOH}$ group.

### 2.2 Electrophilic Aromatic Substitution (EAS) of Phenols
**Priority:** ⭐⭐⭐⭐⭐

The $-\mathrm{OH}$ group is a **strongly activating group** and **ortho/para-directing** because the lone pairs on oxygen provide high electron density to the ring via the $+R$ effect, specifically enriching the 2-, 4-, and 6-positions.

***

#### A. Halogenation (Solvent-Controlled Regioselectivity)
**Priority:** ⭐⭐⭐⭐⭐

* **Case 1: Monobromination in Non-Polar / Low Polarity Media**
  * **Reagents:** $\mathrm{Br_2}$ dissolved in $\mathrm{CS_2}$ or $\mathrm{CHCl_3}$ at low temperature ($T = 273\text{ K}$).
  * **Lewis Acid Requirement:** **No $\mathrm{FeBr_3}$ catalyst is needed** because the ring is already strongly activated by the $-\mathrm{OH}$ group.
  * **Solvent Effect:** In low dielectric media ($\mathrm{CS_2}, \epsilon \approx 2.6$), phenol does not ionize and remains as neutral $\mathrm{C_6H_5OH}$. The ring is moderately activated, leading selectively to mono-substitution.

$$
\mathrm{C_6H_5OH + Br_2 \xrightarrow[\text{273 K}]{\mathrm{CS_2}} \underset{\text{(Minor, sterically hindered)}}{o\text{-Bromophenol}} + \underset{\text{(Major, sterically favored)}}{p\text{-Bromophenol}} + HBr}
$$

* **Case 2: Polybromination in Polar Protane Medium (Bromine Water)**
  * **Reagents:** $\mathrm{Br_2}/\mathrm{H_2O}$ (excess bromine water) at room temperature.
  * **Solvent Effect:** Water ($\epsilon \approx 80$) facilitates complete ionization of phenol into the **phenoxide ion** ($\mathrm{C_6H_5O^-}$). The phenoxide ion has an oxygen with a full negative charge, exerting an exceptionally powerful $+R$ effect that hyper-activates all ortho and para positions.

$$
\mathrm{C_6H_5OH + 3Br_2(aq) \rightarrow \underset{\text{2,4,6-Tribromophenol (White Precipitate)}}{\mathrm{C_6H_2Br_3OH}} \downarrow + 3HBr}
$$

$$
\boxed{\text{Phenol} + 3\mathrm{Br_2(aq)} \rightarrow \text{2,4,6-tribromophenol}\downarrow \text{ (White ppt)} + 3\mathrm{HBr}}
$$

*Application:* Diagnostic test to distinguish phenol from aliphatic alcohols.

***

#### B. Nitration
**Priority:** ⭐⭐⭐⭐⭐

* **Case 1: Dilute Nitric Acid**
  * **Conditions:** $\text{dil. }\mathrm{HNO_3}$ at low temperature ($293\text{ K}$).

$$
\mathrm{C_6H_5OH + \text{dil. } HNO_3 \xrightarrow{293\text{ K}} \underset{\text{(Steam volatile)}}{o\text{-Nitrophenol}} + \underset{\text{(Non-steam volatile)}}{p\text{-Nitrophenol}} + H_2O}
$$

* **Separation Principle (Steam Distillation):**
  * **$o$-Nitrophenol:** Displays **intramolecular hydrogen bonding** (chelation), forming a planar 6-membered ring. This prevents intermolecular associations, lowering boiling point and enhancing volatility in steam.
  * **$p$-Nitrophenol:** Displays extensive **intermolecular hydrogen bonding** causing molecular association, giving it a much higher boiling point and low volatility.

```
Intramolecular H-bonding in o-Nitrophenol:
         O - H ····· O
        /             \\
      (Ar)             N = O
        \             /
         -------------
```

* **Case 2: Concentrated Nitric Acid**
  * **Conditions:** $\text{conc. }\mathrm{HNO_3} + \text{conc. }\mathrm{H_2SO_4}$.

$$
\mathrm{C_6H_5OH + 3\text{ conc. } HNO_3 \xrightarrow{\text{conc. } H_2SO_4} \underset{\text{2,4,6-Trinitrophenol (Picric Acid)}}{\mathrm{C_6H_2(NO_2)_3OH}} + 3H_2O}
$$

* *Crucial NCERT Caveat:* The yield of picric acid via direct nitration is **very poor** because concentrated $\mathrm{HNO_3}$ oxidizes the electron-rich aromatic ring to benzoquinone and tarry matter.
* *Modern Industrial Route:*
  1. Sulfonation of phenol with conc. $\mathrm{H_2SO_4}$ yields phenol-2,4-disulfonic acid.
  2. Treatment with conc. $\mathrm{HNO_3}$ replaces the $-\mathrm{SO_3H}$ groups with $-\mathrm{NO_2}$ via ipso-substitution, preventing oxidative decomposition and yielding high-purity picric acid.

### 2.3 Named Reactions of Phenol

***

#### Kolbe's Reaction (Carboxylation)
**Priority:** ⭐⭐⭐⭐⭐

* **Step 1:** Phenol is converted to sodium phenoxide by treatment with $\mathrm{NaOH}$. The phenoxide ion is more nucleophilic than neutral phenol toward weak electrophiles.
* **Step 2:** Sodium phenoxide is treated with carbon dioxide ($\mathrm{CO_2}$, a weak electrophile) under elevated pressure ($4\text{ to }7\text{ atm}$) and temperature ($400\text{ K}$).
* **Step 3:** Acidification of the intermediate yields salicylic acid.

$$
\mathrm{C_6H_5OH + NaOH \rightarrow C_6H_5O^-Na^+ + H_2O}
$$

$$
\mathrm{C_6H_5O^-Na^+ + CO_2 \xrightarrow[400\text{ K}]{4-7\text{ atm}} \text{Sodium Salicylate Intermediate} \xrightarrow{H^+} \underset{\text{Salicylic Acid (2-Hydroxybenzoic acid)}}{\mathrm{C_6H_4(OH)(COOH)}}
$$

$$
\boxed{\text{Major Product: Salicylic Acid (ortho isomer predominates due to sodium ion chelation)}}
$$

***

#### Reimer-Tiemann Reaction (Formylation)
**Priority:** ⭐⭐⭐⭐⭐

* **Reagents:** Chloroform ($\mathrm{CHCl_3}$) and aqueous sodium hydroxide ($\mathrm{NaOH}$) at $340\text{ K}$, followed by acid hydrolysis.
* **Active Electrophile:** **Dichlorocarbene ($:\mathrm{CCl_2}$)**.
* **Generation of Electrophile ($\alpha$-elimination):**

$$
\mathrm{OH^- + CHCl_3 \rightleftharpoons H_2O + ^-:\mathrm{CCl_3} \xrightarrow{\text{slow (-Cl^-)}} :\mathrm{CCl_2} \quad (\text{Neutral, 6-electron, electron-deficient species})}
$$

* **Detailed Step-by-Step Mechanism:**
  1. Attack of phenoxide ion on $:\mathrm{CCl_2}$ produces an intermediate carbanion at the ortho position.
  2. Proton transfer restores aromaticity, yielding a benzylidene dichloride intermediate.
  3. Alkaline hydrolysis replaces the two chlorines with a geminal diol, which eliminates water to form an aldehyde group.
  4. Acidification produces **salicylaldehyde** (2-hydroxybenzaldehyde).

$$
\mathrm{C_6H_5OH \xrightarrow[\text{(ii) } H^+]{\text{(i) } CHCl_3 + NaOH} \underset{\text{Salicylaldehyde (Major)}}{\mathrm{C_6H_4(OH)(CHO)}} + 2NaCl + 2H_2O}
$$

* *Variation:* If **carbon tetrachloride ($\mathrm{CCl_4}$)** is used instead of $\mathrm{CHCl_3}$, the product formed after hydrolysis is **salicylic acid**:

$$
\mathrm{C_6H_5OH \xrightarrow[\text{(ii) } H^+]{\text{(i) } CCl_4 + NaOH} \mathrm{C_6H_4(OH)(COOH)}}
$$

***

### 2.4 Oxidation and Reduction Reactions
**Priority:** ⭐⭐⭐⭐

#### Reaction with Zinc Dust (Deoxygenation / Reduction)
Vapor of phenol passed over heated zinc dust removes the oxygen atom completely, producing benzene:

$$
\mathrm{C_6H_5OH + Zn \xrightarrow{\Delta} C_6H_6 + ZnO}
$$

$$
\boxed{\Delta H < 0, \quad \text{Conversion of Phenol to Benzene}}
$$

#### Oxidation with Chromic Acid / Alkaline $\mathrm{K_2S_2O_8}$
Phenol oxidizes slowly in the presence of air or rapidly with acidified sodium dichromate ($\mathrm{Na_2Cr_2O_7} / \mathrm{H_2SO_4}$) to give a conjugated diketone:

$$
\mathrm{C_6H_5OH + [O] \xrightarrow{\mathrm{Na_2Cr_2O_7 / H_2SO_4}} \underset{\text{benzo-1,4-quinone (p-Benzoquinone)}}{\mathrm{O=C_6H_4=O}}}
$$

*Physical Consequence:* Pure phenol is colorless, but turns reddish-pink upon prolonged exposure to air due to the formation of $p$-benzoquinone and its charge-transfer complexes (phenoquinone).

### Question 1 [CBSE Board 2024, 3 Marks]
**(a)** How do you explain that phenol is more acidic than ethanol?  
**(b)** Write the chemical reaction for the preparation of Aspirin from salicylic acid.  
**(c)** Give a chemical test to distinguish between Phenol and Benzyl alcohol.

**Answer & Marking Scheme:**
*(a) Acidity Rationale [1 Mark]:*  
Ionization of phenol generates the phenoxide ion ($\mathrm{C_6H_5O^-}$), which is stabilized by resonance over the ortho/para positions of the benzene ring. Ionization of ethanol generates the ethoxide ion ($\mathrm{CH_3CH_2O^-}$), where the negative charge is localized on the oxygen and destabilized by the $+I$ inductive effect of the ethyl group. Thus, phenoxide is significantly more stable than ethoxide.

*(b) Aspirin Synthesis [1 Mark]:*

$$
\mathrm{C_6H_4(OH)(COOH) + (CH_3CO)_2O \xrightarrow{\text{conc. } H_2SO_4} C_6H_4(OCOCH_3)(COOH) + CH_3COOH}
$$

*(c) Diagnostic Distinguishing Test [1 Mark]:*  
Add neutral $\mathrm{FeCl_3}$ solution to both compounds:
* **Phenol:** Gives a characteristic **violet/purple coloration** due to formation of the complex ion $[\mathrm{Fe(OC_6H_5)_6}]^{3-}$.
* **Benzyl alcohol ($\mathrm{C_6H_5CH_2OH}$):** Being an aliphatic/aralkyl alcohol, it gives **no characteristic color change** with neutral $\mathrm{FeCl_3}$.
*(Alternative test: Add bromine water; phenol gives a white precipitate of 2,4,6-tribromophenol, benzyl alcohol does not).*

### Question 2 [CBSE Board 2023, 2 Marks]
Account for the following:
**(i)** $o$-Nitrophenol is more steam-volatile than $p$-nitrophenol.  
**(ii)** Phenol does not give a protonation reaction readily like aliphatic alcohols.

**Answer & Marking Scheme:**
*(i) [1 Mark]:*  
$o$-Nitrophenol has **intramolecular hydrogen bonding** (within the same molecule), preventing association with neighboring molecules. $p$-Nitrophenol exhibits extensive **intermolecular hydrogen bonding**, causing high molecular association and a higher boiling point. Hence, $o$-nitrophenol is steam volatile.

*(ii) [1 Mark]:*  
In phenol, the lone pairs of electrons on the oxygen atom are delocalized into the aromatic ring through resonance ($+R$ effect), acquiring a partial positive charge ($\delta+$). This significantly reduces the electron density on oxygen, making it unavailable to accept a proton ($\mathrm{H^+}$). In contrast, aliphatic alcohols have localized lone pairs on oxygen, further enhanced by the $+I$ effect of alkyl groups.

### Question 3 [CBSE Board 2022 Term-2, 3 Marks]
Give the structures and IUPAC names of products $A, B$, and $C$ in the following sequence:

$$
\mathrm{Phenol \xrightarrow{Zn\text{ dust, }\Delta} A \xrightarrow{CH_3Cl / \text{anhyd. } AlCl_3} B \xrightarrow[\text{(ii) } H_3O^+ / \Delta]{\text{(i) } O_2, \Delta} C + D}
$$

**Solution:**
1. $\mathrm{C_6H_5OH + Zn \xrightarrow{\Delta} A}$:  
   $A$ is **Benzene** ($\mathrm{C_6H_6}$).
2. $\mathrm{Benzene + CH_3Cl \xrightarrow{\text{anhyd. } AlCl_3} B}$ (Friedel-Crafts Alkylation):  
   $B$ is **Toluene / Methylbenzene** ($\mathrm{C_6H_5CH_3}$).
3. **Synthesis of Phenol via Cumene Process:**  
   *(Wait: Toluene with $\mathrm{O_2}$ gives benzoic acid, but if the substrate is converted to Cumene using $\mathrm{CH_3-CH=CH_2}$)*:  
   If step is: $\mathrm{Benzene + CH_3CH=CH_2 \xrightarrow{H_3PO_4} \text{Cumene} \xrightarrow{O_2, H^+} Phenol + Acetone}$.  
   Here, for the classic Cumene conversion:
   

$$
\text{Cumene } \mathrm{C_6H_5CH(CH_3)_2 \xrightarrow{O_2} \text{Cumene hydroperoxide} \xrightarrow{H_3O^+} \underset{(C)}{\text{Phenol}} + \underset{(D)}{\text{Propan-2-one (Acetone)}}}
$$

   * IUPAC Name of $C$: **Phenol** (or Benzenol).
   * IUPAC Name of $D$: **Propan-2-one**.

### Question 5 [CBSE Board 2020, 3 Marks]
An organic compound $A$ ($\mathrm{C_6H_6O}$) gives a violet color with neutral $\mathrm{FeCl_3}$. Compound $A$ on treatment with $\mathrm{CHCl_3}$ and $\mathrm{NaOH}$ yields compound $B$. Compound $B$ on catalytic reduction gives compound $C$ ($\mathrm{C_7H_8O_2}$). Identify $A, B$, and $C$, and write the chemical reactions involved.

**Solution:**
1. **Identification of $A$:** Molecular formula $\mathrm{C_6H_6O}$ and violet color with neutral $\mathrm{FeCl_3}$ indicates $A$ is **Phenol** ($\mathrm{C_6H_5OH}$).
2. **Identification of $B$:** Treatment of phenol with $\mathrm{CHCl_3} + \mathrm{NaOH}$ is the Reimer-Tiemann reaction. Compound $B$ is **Salicylaldehyde** ($\mathrm{2-HOC_6H_4CHO}$).
3. **Identification of $C$:** Reduction of the aldehyde group ($-\mathrm{CHO}$) of salicylaldehyde with $\mathrm{H_2 / Ni}$ yields a primary alcohol:
   

$$
\mathrm{2-HOC_6H_4CHO + 2[H] \xrightarrow{Ni} \underset{\text{2-(Hydroxymethyl)phenol / 2-Hydroxybenzyl alcohol}}{\mathrm{2-HOC_6H_4CH_2OH}} \quad (\text{Formula: } C_7H_8O_2)}
$$

* $A = \text{Phenol}$
* $B = \text{Salicylaldehyde (2-hydroxybenzaldehyde)}$
* $C = \text{2-Hydroxybenzyl alcohol}$

# 4. Examiner Traps & Common Student Mistakes

***

| Reaction / Concept | Common Student Error | NCERT-Strict Correct Fact |
| :--- | :--- | :--- |
| **Bromination of Phenol** | Writing $\mathrm{FeBr_3}$ or $\mathrm{AlBr_3}$ as catalyst in reaction with $\mathrm{Br_2}/\mathrm{CS_2}$. | **No Lewis acid catalyst is required.** Phenol is so strongly activated by $+R$ of $-\mathrm{OH}$ that it polarizes $\mathrm{Br_2}$ directly. |
| **Bromine Water Test** | Writing $p$-bromophenol as the product with $\mathrm{Br_2}/\mathrm{H_2O}$. | Bromine water ionizes phenol to phenoxide, forming **2,4,6-tribromophenol (white ppt)**. |
| **Reimer-Tiemann Intermediate** | Identifying electrophile as $\mathrm{CCl_3^-}$ or carbocation $\mathrm{CH}^+$. | Electrophile is **neutral Dichlorocarbene ($:\mathrm{CCl_2}$)**, formed via $\alpha$-elimination. |
| **Aspirin Synthesis** | Writing that the $-\mathrm{COOH}$ group of salicylic acid is acetylated to give an ester. | The **phenolic $-\mathrm{OH}$ group is acetylated**, producing acetylsalicylic acid ($-\mathrm{OCOCH_3}$). |
| **Kolbe's Reaction Reagent** | Writing $\mathrm{CO_2}$ directly on phenol without base. | Phenol is unreactive toward the weak electrophile $\mathrm{CO_2}$. It must first be converted to **sodium phenoxide ($\mathrm{C_6H_5O^-Na^+}$)** with $\mathrm{NaOH}$. |
| **Separation of Nitrophenols** | Confusing which isomer is steam-volatile. | **$o$-Nitrophenol is steam-volatile** (intramolecular H-bond); **$p$-Nitrophenol is NOT** (intermolecular H-bond). |
| **Distinguishing Alcohol vs. Phenol** | Using Lucas Reagent ($\mathrm{ZnCl_2} + \text{conc. }\mathrm{HCl}$) to test Phenol. | Phenol **does not react** with Lucas reagent because the $\mathrm{C-O}$ bond has partial double-bond character. Use neutral $\mathrm{FeCl_3}$ or $\mathrm{Br_2}/\mathrm{H_2O}$. |

### Quick Mnemonics

* **Reimer-Tiemann Electrophile Generation:**
  

$$
C-H-C-l-3 \xrightarrow{\text{lose } \mathrm{H^+}, \text{ lose } \mathrm{Cl^-}} \mathbf{:\!CCl_2} \quad \text{("Alpha-Elimination strips two sides")}
$$

* **Separation of Nitrophenols:**
  * **IN**tra = **IN**dependent = **IN** volatile steam ($o$-isomer).
  * **INTER** = **INTER**locked network = Non-volatile ($p$-isomer).
* **Kolbe vs. Reimer-Tiemann Products:**
  * **K**olbe adds **C**arboxyl ($\mathrm{CO_2} \rightarrow -\mathrm{COOH}$, Salicylic acid).
  * **R**eimer adds **F**ormyl ($\mathrm{CHCl_3} \rightarrow -\mathrm{CHO}$, Salicylaldehyde).
